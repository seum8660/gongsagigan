# 공사기간 산정 검토 대시보드

공공 건설공사의 적정 공사기간을 두 가지 방식으로 산정·비교하는 단일 HTML 대시보드입니다. GitHub Pages(`https://seum8660.github.io/gongsagigan/`)로 여는 것을 기준으로 합니다. 인터넷 없이 쓸 때는 `index-offline.html`을 엽니다.

## 산정 방식

| 구분 | 방식 | 산출 구조 |
| --- | --- | --- |
| 검토1안 | 표준품셈 | 준비기간 + 비작업일수 + 주공정(CP) 순작업일수 + 정리기간 |
| 검토2안 | 시설물별 산정공식 | 회귀식 Y(비작업일수 포함) + 준비기간 + 정리기간 |

두 안의 총 공사기간을 비교해 채택안을 표시하며, 총공사비가 입력되지 않으면 검토2안은 산정하지 않습니다. 시설물 유형별 적용범위(예: 학교 200억원 이하)를 벗어나면 경고를 표시합니다.

## 비작업일수 자동 산정

```
비작업일수 = A(기상) + B(법정공휴일) − C(중복)
C = A × B ÷ 달력일수,  월 하한 8일(주40시간 기준)
```

착공예정일과 관측지점을 넣으면 월별로 안분하여 자동 계산합니다.

### 기상 데이터

전국 종관기상관측(ASOS) 98개 지점의 2016.09~2026.09 일자료(약 35만 건)를 사용합니다. 월별 집계값은 `index.html`에 들어 있고, 기준값을 바꾸면 해당 지점의 일자료를 기상청 API로 불러옵니다. 출처는 기상자료개방포털(`data.kma.go.kr`)이며, 다음 요소로 작업제한일을 판정합니다.

| 요인 | 기본 기준값 |
| --- | --- |
| 강우 | 일강수량 5mm 이상 (구조물공사 10mm) |
| 강풍 | 최대순간풍속 15m/s 이상 |
| 혹서 | 최고기온 33℃ 이상 |
| 동절기 | 최고기온 0℃ 이하 |
| 강설 | 일 최심신적설 5cm 이상 |

기준값은 대시보드에서 직접 수정할 수 있고, 값을 바꾸면 기상청 API로 해당 지점의 일자료를 받아 재집계합니다(인증키 필요). 인증키가 없거나 불러오지 못하면 기본 기준값 집계로 계산하고 안내 문구를 표시합니다. 요인별 반영 여부, 월 하한, 공휴일 반영, 중복 공제, 기상 보정계수도 조정 가능하며 기준값과의 차이를 함께 표시합니다.

### 기상 자료 추가

기상자료개방포털에서 받은 ASOS 일자료(CSV·XLSX·XLS)를 끌어다 놓으면 지점별로 집계되어 관측지역 목록에 추가·갱신됩니다. 필요한 항목은 지점명, 일시, 최저기온, 최고기온, 일강수량, 최대 순간 풍속, 일 최심신적설입니다. 추가한 자료는 브라우저에 저장되며 "추가 자료 삭제"로 내장 데이터만 남길 수 있습니다.

### 기상청 API 연동

옵션 화면의 "기상청 API 연동" 칸에 공공데이터포털 인증키를 넣으면 최근 10년 일자료를 직접 받아 비작업일수를 다시 집계합니다.

**인증키 받기**

1. 공공데이터포털(data.go.kr) 가입 후 로그인
2. "기상청_지상(종관, ASOS) 일자료 조회서비스" 검색 → 활용신청 (보통 자동 승인)
3. 마이페이지 → 개발계정에서 일반 인증키 복사 (Encoding·Decoding 어느 쪽이든 가능)
4. 승인 직후 1~2시간은 키가 활성화되지 않아 오류가 날 수 있음

**사용**

| 항목 | 설명 |
| --- | --- |
| 인증키 | 복사한 키 입력. 이 브라우저에만 저장되며 깃허브에는 올라가지 않음 |
| 프록시 주소 | 평소 비워 둠. CORS 차단 시에만 중계 주소 입력 |
| 선택 지점 최신화 | 선택한 관측지점의 최근 10년 자료 수신 (지점당 약 4회 호출) |
| 전체 지점 일괄 최신화 | 98지점 전체 수신 (약 400회 호출, 수 분 소요, 개발계정 일 10,000회 한도 내) |
| 인증키 지우기 | 저장된 키 삭제 |
| 추가 자료 삭제 | 받은 자료를 지우고 내장 자료로 복귀 |

받은 자료는 브라우저에 저장되어 다음에 열 때도 적용됩니다.

**오류 대처**

| 메시지 | 원인 | 해결 |
| --- | --- | --- |
| SERVICE_KEY_IS_NOT_REGISTERED | 키 미활성 또는 복사 오류 | 1~2시간 후 재시도, 다른 형식의 키 입력 |
| Failed to fetch / CORS 차단 | 포털이 브라우저 직접 요청을 차단 | 프록시 주소 입력 |
| 자료 없음 | 폐지 지점 또는 관측 공백 | 인근 지점 사용 |

## 출력

인쇄 미리보기는 Paged.js로 A4 세로에 조판합니다. 여백은 위 30mm · 왼쪽 20mm · 오른쪽 15mm · 아래 15mm이며, 표는 페이지 경계에서 분할되고 머리행이 반복됩니다. 쪽번호는 미리보기 조판에 표시됩니다(브라우저 인쇄 출력에는 브라우저의 머리글·바닥글 설정을 사용). 미리보기는 CDN에서 Paged.js를 불러오므로 인터넷 연결이 필요하고, 브라우저 인쇄(PDF 저장)는 오프라인에서도 동작합니다.

```
gongsagigan/
```

## 깃허브 배포

1. 위 파일을 저장소 최상위에 업로드 (Add file → Upload files)
2. Settings → Pages → Branch: main / (root) 저장
3. 1~2분 후 `https://seum8660.github.io/gongsagigan/` 에서 열림
