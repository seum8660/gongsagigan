# 공사기간 산정 검토 대시보드

공공 건설공사의 적정 공사기간을 두 가지 방식으로 산정·비교하는 단일 HTML 대시보드입니다. 별도 설치나 서버 없이 `dashboard.html` 파일 하나를 브라우저로 열면 동작합니다.

## 산정 방식

| 구분 | 방식 | 산출 구조 |
| --- | --- | --- |
| 검토1안 | 표준품셈 | 준비기간 + 비작업일수 + 주공정(CP) 순작업일수 + 정리기간 |
| 검토2안 | 시설물별 산정공식 | 회귀식 Y(비작업일수 포함) + 준비기간 + 정리기간 |

두 안의 총 공사기간을 비교해 채택안을 표시하며, 총공사비가 입력되지 않으면 검토2안은 산정하지 않습니다. 시설물 유형별 적용범위(예: 학교 200억원 이하)를 벗어나면 경고를 표시합니다.

## 비작업일수 자동 산정

```
비작업일수 = A(기상) + B(법정공휴일) − C(중복)
C = A × B ÷ 달력일수,  월 하한 8일(주40시간 기준)
```

착공예정일과 관측지점을 넣으면 월별로 안분하여 자동 계산합니다.

### 기상 데이터

전국 종관기상관측(ASOS) 98개 지점의 2016.09~2026.09 일자료(약 35만 건)를 파일에 내장했습니다. 출처는 기상자료개방포털(`data.kma.go.kr`)이며, 다음 요소로 작업제한일을 판정합니다.

| 요인 | 기본 기준값 |
| --- | --- |
| 강우 | 일강수량 5mm 이상 |
| 강풍 | 최대 순간 풍속 10m/s 이상 |
| 혹서 | 최고기온 33℃ 이상 |
| 혹한 | 최저기온 −5℃ 이하 |
| 강설 | 일 최심신적설 1cm 이상 |

기준값은 대시보드에서 직접 수정할 수 있고, 값을 바꾸면 내장 일자료를 즉시 재집계합니다. 요인별 반영 여부, 월 하한, 공휴일 반영, 중복 공제, 기상 보정계수도 조정 가능하며 기준값과의 차이를 함께 표시합니다.

### 기상 자료 추가

기상자료개방포털에서 받은 ASOS 일자료(CSV·XLSX·XLS)를 끌어다 놓으면 지점별로 집계되어 관측지역 목록에 추가·갱신됩니다. 필요한 항목은 지점명, 일시, 최저기온, 최고기온, 일강수량, 최대 순간 풍속, 일 최심신적설입니다. 추가한 자료는 브라우저에 저장되며 "추가 자료 삭제"로 내장 데이터만 남길 수 있습니다.

## 출력

인쇄 미리보기는 Paged.js로 A4 세로에 조판합니다. 여백은 위 30mm · 왼쪽 20mm · 오른쪽 15mm · 아래 15mm이며, 표는 페이지 경계에서 분할되고 머리행이 반복됩니다. 쪽번호는 하단에 자동으로 붙습니다. 미리보기는 CDN에서 Paged.js를 불러오므로 인터넷 연결이 필요하고, 브라우저 인쇄(PDF 저장)는 오프라인에서도 동작합니다.

## 기타

- 다크 모드와 고대비 모드를 지원하며 설정은 브라우저에 저장됩니다.
- 공정표의 막대는 드래그로 위치를 조정할 수 있습니다(더블클릭 시 자동배치 복귀).
